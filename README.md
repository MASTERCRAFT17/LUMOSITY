# LUMOSITY 🧠
### Sensory & Perception Lab

**Lumosity** is an experimental browser-based brain training and sensory perception game designed to challenge the way people observe, react, remember, and process visual information.

The project brings together interactive mini-games, perception challenges, scoring systems, and player progression in one experience.

## 🎮 Features

- **10 Interactive Modules** – A collection of different sensory and perception-based challenges.
- **Multiple Game Modes** – Daily challenges, random selections, and ACE mode.
- **Player Statistics** – Track scores and monitor your performance.
- **Level Progression** – Progress through challenges as you play.
- **Sound Effects** – Audio feedback during gameplay.
- **Customisation** – Theme settings and personalised gameplay preferences.
- **Browser-Based** – Play directly in your web browser without installing an application.

## 🛠️ Technologies Used
