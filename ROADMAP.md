# Lumosity — Development Roadmap

This roadmap outlines proposed development goals for Lumosity. Priorities may change as the project evolves.

## ✅ Current Features

- [x] 10 interactive sensory and perception modules
- [x] Daily challenge mode
- [x] Random 10 mode
- [x] ACE mode
- [x] Player statistics and scoring
- [x] Level progression
- [x] Sound effects
- [x] Theme customisation
- [x] Local progress persistence
- [x] Browser-based gameplay

## 🚧 Short-Term Goals

- [ ] Improve gameplay responsiveness and performance
- [ ] Refine the user interface and user experience
- [ ] Improve accessibility and keyboard support
- [ ] Identify and fix gameplay bugs
- [ ] Improve mobile browser compatibility

## 🔮 Future Ideas

- [ ] Add more sensory and perception challenges
- [ ] Introduce additional difficulty levels
- [ ] Expand player statistics and performance insights
- [ ] Add achievements and rewards
- [ ] Explore cloud-based progress synchronisation
- [ ] Explore user accounts and leaderboards

## 🤝 Community Contributions

Community feedback, bug reports, and feature suggestions will help shape the future of Lumosity.

See [CONTRIBUTING.md](CONTRIBUTING.md) to learn how to contribute.
