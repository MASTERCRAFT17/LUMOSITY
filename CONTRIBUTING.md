# Contributing to Lumosity

Thank you for your interest in contributing to Lumosity!

Lumosity is an independent browser-based brain training and sensory perception project. Contributions, suggestions, and feedback are welcome.

## How to Contribute

### 1. Report Bugs
- Check whether the issue has already been reported.
- Open a new GitHub Issue.
- Describe the problem and the steps required to reproduce it.
- Include screenshots or relevant details when possible.

### 2. Suggest Features
- Open a GitHub Issue describing your idea.
- Explain how the proposed feature could improve the experience.
- Include examples or references where helpful.

### 3. Submit Code Changes
- Fork the repository.
- Create a separate branch for your changes.
- Make your changes and test them in a browser.
- Submit a Pull Request explaining what you changed and why.

## Contribution Guidelines

- Keep changes focused and easy to understand.
- Avoid breaking existing game functionality.
- Test gameplay and interactions before submitting changes.
- Write clear descriptions for issues and pull requests.
- Respect the existing project structure.

## Questions and Feedback

For questions, suggestions, or feedback, please use the GitHub Issues section.

Thank you for helping improve Lumosity!
